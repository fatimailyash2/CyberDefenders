CyberDefenders - Hands-On SOC & Digital Forensics Lab Portfolio

Ongoing hands-on cybersecurity lab portfolio focused on practical SOC, threat intelligence, network forensics, malware analysis, endpoint forensics, and threat hunting. Investigating realistic attack scenarios using tools and techniques to identify Indicators of Compromise (IOCs), analyze malicious activity, reconstruct attack timelines, and investigate compromised systems.

Labs include investigations involving:

Network traffic analysis using Wireshark
Threat intelligence and IOC extraction
Malware analysis and malicious document investigation
Windows endpoint and Sysinternals artifact analysis
SIEM-based threat hunting using QRadar
Phishing and data exfiltration investigations
Windows event and Sysmon log analysis
Identification of attacker TTPs, persistence mechanisms, lateral movement, and privilege escalation
Analysis of malicious scripts, PDFs, keyloggers, and web-based attacks
